## OPEN Business World — Site e-commerce (cest mon 1 gros project)

Site vitrine + boutique en ligne pour OPEN Business World, magasin informatique basé à Abidjan (Plateau, Immeuble Mali). Vente de PC, PC gamer, imprimantes, smartphones, périphériques et accessoires.

## À propos du projet

C'est mon premier gros projet en tant que développeur junior chez OBW. Le site est en train d'être construit petit à petit, en apprenant en même temps.
je l'ai réaliser seule avec IA pour la comprehension + la vitesse

## Comment lancer le site (frontend uniquement pour l'instant)

Pas besoin de serveur pour l'instant, le site est en HTML statique. J'utilise l'extension Live Server sur VS Code pour tester en local :

1. Ouvrir le dossier `frontend/` dans VS Code
2. Clic droit sur `index.html` → "Open with Live Server"
3. Le site s'ouvre sur `http://127.0.0.1:5500`
